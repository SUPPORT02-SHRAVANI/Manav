The two doctypes keep the same things in different fields. Each print format therefore only gathers the values of its doctype into one variable `q` and then includes this file, which draws the page from `q`. A change of the look is made here once and shows in both. It follows the design the user supplied on 2026-10-13 (file quotation_template (2).html, "Modern Minimalist Black & White"). That file was a sample with the figures typed in, styled by scripts loaded from the internet; here the same look is plain CSS and tables, because the PDF maker (wkhtmltopdf) runs no such scripts and knows neither flexbox nor grid.
